# مراقب مودل جامعة فهد بن سلطان → إشعارات Poke

سكربت بايثون يدخل حساب المودل حقك في `elearning.fbsu.edu.sa`، ويكتشف أي جديد
(واجبات، محتوى/شباتر جديدة بالمقررات، إشعارات، حضور)، ويرسله لك عن طريق Poke.
يشتغل تلقائيًا **مجانًا** على GitHub Actions كل 30 دقيقة، بدون ما تحتاج جهازك
يكون شغال.

> **مهم:** خله المستودع (repo) **Private** لأن فيه بيانات حسابك الجامعي.

---

## الخطوة 1: أنشئ مستودع (Repo) خاص على GitHub

1. إذا ما عندك حساب GitHub، أنشئ واحد من https://github.com/signup
2. روح https://github.com/new
3. اسم المستودع: مثلاً `fbsu-moodle-watcher`
4. اختر **Private**
5. اضغط **Create repository**

ثم ارفع كل ملفات هذا المجلد (`moodle_watcher.py`, `requirements.txt`,
`.gitignore`, `.github/workflows/watch.yml`) للمستودع. أسهل طريقة:

- من صفحة المستودع اضغط **Add file → Upload files** واسحب الملفات.
- انتبه: مجلد `.github/workflows/watch.yml` لازم يضل بنفس المسار بالضبط
  (يعني فيه مجلد اسمه `.github` وبداخله `workflows`).

---

## الخطوة 2: احصل على مفتاح Poke API

1. سجّل حساب في https://poke.com إذا ما عندك (يدعم التسجيل عبر
   Apple Messages / Telegram / WhatsApp / RCS - اختر الطريقة الأسهل لك).
2. أرسل أي رسالة لـ Poke مرة وحدة عشان يتفعّل حسابك.
3. روح لصفحة **Kitchen**: https://poke.com/kitchen
4. دوّر على قسم **API Keys** أو **Advanced** واعمل **Create new API key**
   (اختر النوع V2 إذا طلب منك نوع).
5. انسخ المفتاح فورًا (بعض الأنظمة ما تعرضه مرة ثانية).

---

## الخطوة 3: ضيف الأسرار (Secrets) بالمستودع

بمستودعك على GitHub:

`Settings` → `Secrets and variables` → `Actions` → `New repository secret`

ضيف هذي الأسرار وحدة وحدة:

| اسم السر (Name)     | القيمة |
|---------------------|--------|
| `MOODLE_USERNAME`   | اسم المستخدم حقك بالمودل (نفس اللي تسجل فيه دخول عادي) |
| `MOODLE_PASSWORD`   | كلمة المرور حقك بالمودل |
| `POKE_API_KEY`      | المفتاح اللي نسخته من الخطوة 2 |

(اختياري) `MOODLE_URL` — فقط إذا رابط المودل عندك مختلف عن
`https://elearning.fbsu.edu.sa`.

---

## الخطوة 4: فعّل GitHub Actions وجرّب تشغيل يدوي

1. روح تبويب **Actions** بالمستودع.
2. إذا طلب منك تفعيل الووركفلوز، اضغط **I understand my workflows, go ahead
   and enable them**.
3. من القائمة اليسرى اختر **FBSU Moodle Watcher**.
4. اضغط **Run workflow** (زر رمادي على اليمين) لتجربته يدويًا أول مرة.
5. افتح التشغيل وشوف السجل (Log) — لازم يطلع لك أسفل شي شبيه:
   ```
   مسجل الدخول كـ: ...
   أول تشغيل: تم حفظ الحالة الحالية كنقطة بداية بدون إرسال كل السجل القديم.
   ```
   وبنفس الوقت بتوصلك رسالة ترحيبية على Poke تأكّد إن كل شي يشتغل.

إذا طلعت لك رسالة خطأ في تسجيل الدخول، تأكد إن `MOODLE_USERNAME` و
`MOODLE_PASSWORD` مطابقين تمامًا لبيانات دخولك بالمودل.

---

## بعد كذا؟

الووركفلو بيشتغل تلقائيًا كل 30 دقيقة من تلقاء نفسه (`cron` بملف
`watch.yml`)، ويحفظ آخر حالة شافها بملف `state.json` بنفس المستودع حتى ما
يكرر نفس الإشعار مرتين. أي تحديث جديد بالموقع (واجب، محتوى جديد بمقرر،
إشعار، حضور) بيوصلك مباشرة برسالة على Poke.

### ملاحظات

- أول تشغيل ما يرسل أي إشعارات عن السجل القديم — فقط يحفظ نقطة البداية،
  وبعدها كل شي جديد بعد هذي اللحظة بيوصلك.
- تغطية الحضور (تحضير/تغييب) تعتمد على كون نظام الحضور بالموقع مفعّل عبر
  خدمة تطبيق الجوال؛ إذا ما كان مفعّل، السكربت يتجاهله تلقائيًا بدون ما يفشل،
  وبيوصلك باقي الأشياء (واجبات/محتوى/إشعارات) عادي.
- إذا تبي تغيّر عدد مرات الفحص، عدّل السطر `cron: "*/30 * * * *"` بملف
  `.github/workflows/watch.yml` (مثلاً `*/60` لكل ساعة).
- ما تشارك أو تنشر مفاتيح `MOODLE_PASSWORD` أو `POKE_API_KEY` لأي أحد،
  وخل المستودع Private دائمًا.
